HyperSnap-DX ver. 5

HyperSnap-DX 5 is a screen capture and image editing
tool for Windows. Captures screens from standard
desktop programs and hard-to-grab DirectX/Direct3D,
3Dfx Voodoo and Glide mode games.

HyperSnap-DX ver. 5 is distributed on "try before you 
buy" principle.  If used without a license, it will add 
Hyperionics stamps to images that you capture or edit 
with it.  To purchase a license, visit our web site at 
http://www.hyperionics.com
